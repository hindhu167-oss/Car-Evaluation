Car Evaluation Dataset

About the Dataset

This repository contains a dataset collected for car evaluation and machine learning analysis.

Dataset Description

The dataset contains information about different cars and their evaluation-related attributes.

File

- "car_evaluation.csv" – Contains the collected car evaluation data.

Purpose

The dataset can be used for:

- Data preprocessing
- Exploratory Data Analysis (EDA)
- Data visualization
- Machine learning
- Car evaluation/prediction

Dataset Attributes

The main attributes included in the dataset are:

- Buying price
- Maintenance cost
- Number of doors
- Passenger capacity
- Luggage boot size
- Safety
- Evaluation/class

Usage

The dataset can be downloaded and used for educational and machine learning purposes.
